# Bundled fonts

The looks in `app/src/main/java/com/acechase/kidclock/looks/` draw with these typefaces, shipped
in `app/src/main/res/font/`. All are published under the SIL Open Font License 1.1
(https://openfontlicense.org) and were downloaded from Google Fonts on 2026-10-30.

| File | Family | Look |
| --- | --- | --- |
| `fredoka_semibold.ttf` | Fredoka SemiBold | Bold, Magnets |
| `oswald_medium.ttf` | Oswald Medium | Stacked |
| `caveat_bold.ttf` | Caveat Bold | Sketch |
| `patrick_hand.ttf` | Patrick Hand | Sketch |
| `bungee_shade.ttf` | Bungee Shade | Whacky |
| `monoton.ttf` | Monoton | Whacky |
| `rubik_mono_one.ttf` | Rubik Mono One | Whacky |
| `press_start_2p.ttf` | Press Start 2P | Pixel |

Classic and Analog use the device's Roboto.
